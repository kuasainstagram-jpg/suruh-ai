# Suruh AI — Edit video guna phone

Skill percuma untuk **Claude Code**: edit video tegak (9:16) dengan **30 gaya** — hook, caption, kad angka, transisi & penutup — hanya dengan menampal arahan dari dashboard.

**Mula di sini:** [suruhaieditvideogunaphone.com](https://suruhaieditvideogunaphone.com)

## Cara guna (ringkas)
1. Daftar percuma di laman di atas → pilih gaya → tekan **Salin arahan**.
2. Buka **Claude → Code**, pilih repo ini (atau fork anda), tampal arahan + link video Google Drive.
3. Tunggu ±5–10 minit → muat turun MP4.

Skill berada di `.claude/skills/gaya-cikgu-mirul/`. Katalog gaya: `catalog.md`.
