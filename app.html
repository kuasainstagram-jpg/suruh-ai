    Masuk grup WhatsApp

    Tema Wow

    🎁 Hadiah ahli

    Satu tema = video anda nampak macam diedit penuh: konsep, B-roll & kapsyen automatik. Pilih satu, boleh campur dengan gaya di bawah.

    Hadiah anda

    Kawan dikira bila mereka daftar guna link anda dan sahkan grup dari telefon mereka sendiri. Pendaftaran palsu dibatalkan. Lihat peraturan

    Cara guna (6 langkah)
    Persediaan · sekali sahaja
    • Akaun Claude yang ada Claude Code (app Claude atau claude.ai).
    • Akaun GitHub percuma → buka repo suruh-ai → tekan Fork.
    • Dalam Claude → Code → sambung GitHub → pilih repo itu.
    1. Sediakan video
      Rakam tegak (9:16). Upload ke Google Drive → Kongsi → “Sesiapa yang ada pautan” → salin link.
    2. Pilih 5–6 gaya
      1 Hook + 1 Caption + 2–3 Kad + 1 Penutup. Atau tekan Pilihkan untuk saya.
    3. Tekan “Salin arahan”
      Kod gaya anda disalin sekali.
    4. Tampal dalam Claude Code
      Sesi baharu → repo suruh-ai → tampal → ganti “Video:” dengan link anda → hantar.
    5. Jawab soalan Claude
      Gaya bertanda Perlu perlukan bahan anda (angka sebenar, nama, gambar).
    6. Muat turun video
      ±5–10 minit. Dapat MP4 penuh + versi WhatsApp.

    Pilih gaya

    Pratonton sahaja. Butang Salin arahan dibuka bila akses anda terbuka.
